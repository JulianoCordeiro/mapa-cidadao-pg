# Mapa Cidadão PG

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

O Mapa Cidadão PG é um site responsivo desenvolvido para permitir que moradores de Ponta Grossa - PR registrem problemas urbanos.

As ocorrências podem estar relacionadas a:

- Iluminação pública
- Asfalto
- Calçadas

O usuário pode informar o tipo do problema, adicionar uma descrição, anexar uma fotografia e marcar a localização da ocorrência em um mapa.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Leaflet
- OpenStreetMap

## Funcionalidades

- Cadastro de ocorrências
- Upload de imagens
- Seleção de categorias
- Localização no mapa
- Geolocalização
- Filtros de ocorrências
- Layout responsivo
- Armazenamento local com LocalStorage

## Objetivo

Utilizar a tecnologia para incentivar a participação da comunidade na identificação e no mapeamento de problemas relacionados à infraestrutura urbana de Ponta Grossa - Paraná.
